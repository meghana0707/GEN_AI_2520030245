
# Week 1 – First LLM API Call

## Aim
To connect a Python application with a Large Language Model (LLM) using an API and generate responses from user prompts.

## Technologies Used
- Python
- OpenAI API / Gemini API
- Visual Studio Code
- Python-dotenv

## Project Structure
```text
Week1/
├── main.py
├── .env
├── .gitignore
└── requirements.txt
```

## Implementation
1. Created a Python project in VS Code.
2. Configured the API key using a `.env` file.
3. Installed the required Python libraries.
4. Created an LLM client.
5. Sent a prompt to the AI model.
6. Displayed the generated response in the terminal.

## Installation
```bash
pip install -r requirements.txt
```

## Execution
```bash
python main.py
```

## Expected Output
The program accepts a prompt and displays an AI-generated response in the terminal.

Example:
```text
LLM Response:
Artificial Intelligence is a technology that
enables machines to perform tasks that
normally require human intelligence.
```

## Learning Outcomes
- Understood LLM API integration.
- Learned how to use API keys.
- Learned secure environment variable management.
- Generated AI responses using Python.

## Conclusion
Successfully implemented the first LLM API call using Python and an AI API.
