# Week 7 – Next-Token Probabilities

## Experiment Title
Next-token probabilities: Inspect logits and top-k candidates from a small open model with Hugging Face Transformers.

## Aim
To load a small open-source language model using Hugging Face Transformers and inspect next-token prediction probabilities by analyzing logits and identifying the top-k candidate tokens.

## Technologies Used
- Python
- Hugging Face Transformers
- PyTorch
- GPT-2 Small Model

## Libraries Required
```bash
pip install transformers torch
```

## Implementation
1. Load the GPT-2 model using Hugging Face Transformers.
2. Load the tokenizer.
3. Accept an input text prompt from the user.
4. Convert the input text into tokens.
5. Pass the tokens to the model to obtain logits.
6. Apply Softmax to convert logits into probabilities.
7. Use Top-K selection to identify the five most probable next tokens.
8. Display the predicted tokens and their probabilities.

## Execution

Run the following command:

```bash
python main.py
```

### Sample Input
```text
Artificial intelligence is
```


*Note: Output probabilities may vary depending on the model and execution environment.*

## Key Concepts

### 1. Logits
Logits are raw numerical scores generated by the language model for possible next tokens.

### 2. Softmax
Softmax converts logits into probabilities between 0 and 1.

### 3. Top-K
Top-K selects the K tokens with the highest prediction probabilities.

## Result
Successfully loaded the GPT-2 model, extracted next-token logits, converted them into probabilities using Softmax, and displayed the top 5 next-token candidates.

## Conclusion
This experiment demonstrates how language models predict the next token using logits and probability distributions. It also helps understand next-token prediction using Hugging Face Transformers and PyTorch.
